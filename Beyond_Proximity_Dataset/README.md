# Beyond Proximity Dataset Reference

This folder is a placeholder reference for the publicly shared sample data used with the DairyCow-SNA repository.

The actual sample dataset is hosted externally and can be downloaded from:

https://drive.google.com/drive/folders/1sP_RqsjEJuXkHw8UJ1wP3fz_waFQeCyj?usp=sharing

The external sample dataset currently contains these top-level directories:

- `Interaction_Feature_Keypoint`
- `Keypoint_Detection`
- `Videos`

If you want to mirror the referenced layout locally, place the downloaded contents under this folder so the resulting structure is:

- `Beyond_Proximity_Dataset/Interaction_Feature_Keypoint`
- `Beyond_Proximity_Dataset/Keypoint_Detection`
- `Beyond_Proximity_Dataset/Videos`

This placeholder exists so the GitHub repository clearly references the sample dataset without storing the actual data in version control.
